# blipb — Power-balance BLI benefit model with uncertainty quantification

Low-order, open-source, reproducible implementation of the Drela (2009) power-balance
boundary-layer-ingestion (BLI) benefit model, unified with the Smith (1993) and Hall et al.
(2017) formulations, coupled to polynomial-chaos + Monte-Carlo uncertainty quantification and
Sobol' global sensitivity analysis.
